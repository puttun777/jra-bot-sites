# REQUIREMENTS（Sites 版）

正本は jra-bot-web `docs/REQUIREMENTS.md`（業務要件）。ここは Sites 移行で変わる点だけを書く。

## 1. 利用者・目的
- 利用者は本人を含め最大 2 名。私的・非営利。サイトは非公開（共有は Sites の対象者設定 + サーバ側の許可リスト）。
- 既存 jra-bot の後継（新規の競馬情報サイトではない）。判定・成績の計算は旧実装と同じ結果にする。

## 2. 必須制約（依頼より）
- ChatGPT Plus の既存契約内。追加の月額・従量課金なし。AWS/GCP/Azure・外部ホスティング・有料 API・OpenAI API を使わない。
- アプリの実行時に Anthropic API を使わない。JV-Link・JRA-VAN を使わない。常時稼働の PC・サーバ・独自ドメインを必要としない。
- 再現性が必要な計算に生成 AI を使わない（判定はすべてプログラム）。

## 3. 機能要件（変更点）
| 要件 | Sites 版 |
|---|---|
| データ取得 | ChatGPT（MCP）・CSV/JSON 手動取込。差分だけ（`get_fetch_plan`）。公開 Web の自動取得は規約確認後 |
| 判定の実行 | 定期（Automations）+ 手動（画面のボタン・ChatGPT）。日付・レース単位で分割可能 |
| 通知 | サイト内表示。Discord は外部通信の確認後 |
| 開催日の判定 | 土日固定ではなく、取得した開催日・レースと手動補正から導出（祝日・変則開催に対応。web と同じ） |
| 欠損時 | オッズ未取得は「分析不能」、組合せの実オッズ未取得は「見送り」、結果未取得は成績で「未確定」として件数を表示 |

## 4. 非機能
- 日本語 UI・PC/スマホ・ダークモード・検索（日付）・ページング・取得日時・読み込み中・未取得・エラーの表示（web の画面を継承）。
- タイムゾーンは Asia/Tokyo（保存は UTC）。
- 試験: `npm run build`・`typecheck`・`lint`・`test`。Sites 上でしか確かめられないものは未検証として管理（SITES_CONSTRAINTS §3）。
